# GitHub Hesabı ve Lab Çalışmaları Duyurusu

Sevgili öğrenciler,

Lab çalışmalarına katılabilmek için bir GitHub hesabınızın bulunması gerekir. Hesabınızı açtıktan sonra GitHub kullanıcı adınızı ders sorumlusuna bildirmeniz yeterlidir; ilgili organizasyon daveti ders sorumlusu tarafından gönderilecektir.

## Günlük kontrol zamanı

GitHub hesap ve organizasyon durumları her gün **17:00-18:00 arasında** kontrol edilecektir. Günlük puan listesi, kontrol tamamlandıktan sonra **18:00'den sonra** güncellenecektir.

Öğrencinin hesabı, kontrol sırasında atanmış GitHub kullanıcı adıyla mevcut görünüyorsa o günün puan katsayısı uygulanır. Organizasyon daveti, hesabı doğrulanan öğrenciye GitHub kullanıcı adı üzerinden gönderilir.

## Puanlama

Başlangıç puanı 100'dür. Hesabın açıldığı güne göre aşağıdaki katsayı uygulanır:

| Hesabın açıldığı gün | Katsayı | 100 puan üzerinden karşılığı |
|---|---:|---:|
| 1. gün | 1.00 | 100 puan |
| 2. gün | 0.80 | 80 puan |
| 3. gün | 0.60 | 60 puan |
| 4. gün | 0.40 | 40 puan |
| 5. gün | 0.20 | 20 puan |
| 5. gün kontrolünden sonra hâlâ açılmamışsa | 0.00 | 0 puan |

Örnek: Çarşamba akşamı yapılan kontrolde hesabı tamamlanmış görünen öğrencinin puanı `100 x 0.80 = 80` olarak hesaplanır. Dördüncü gün tamamlayan öğrencinin puanı `100 x 0.40 = 40` olur.

Her kursun puan listesi ayrı tutulacaktır. `se2009-26` ve `se3509-26` organizasyonları birbirinden bağımsız değerlendirilecektir.

## Katılım ve mazeret

Hesabı açılmayan veya ilgili organizasyona katılmayan öğrenciler lab ödevlerine dahil edilemez. Geçerli ve önceden bildirilmiş bir mazereti olan öğrencilerin kontrol saatinden önce ders sorumlusu ile iletişime geçmesi gerekir. Gerekçesiz gecikmeler puanlama tablosuna aynen yansıtılır.

GitHub hesabınızı açtıktan sonra kullanıcı adınızı ders sorumlusuna bildiriniz. Organizasyon daveti GitHub üzerinden hesabınıza gönderilecektir. Davet geldiğinde GitHub bildirimlerinizi ve hesabınıza bağlı e-posta adresini kontrol ederek daveti kabul ediniz.

Bu duyuru `se2009-26` ve `se3509-26` organizasyonlarının `00-start-here` depolarında yayımlanacaktır.
