# DYS Duyurusu: GitHub ve Zorunlu Hazırlık Çalışmaları

Bu dersin hazırlık çalışmaları GitHub üzerinden yürütülecektir. Başlangıç
belgelerine ve bağlantılara organizasyonumuzdaki 00-start-here deposundan
ulaşabilirsiniz.

Hazırlık çalışmalarını aşağıdaki sırayla tamamlayın:

1. PREP-00: Laboratuvar kurallarını okuyun ve onay çalışmasını teslim edin.
2. PREP-01: GitHub hesabı ve temel çalışma akışını uygulayın.
3. PREP-02: DataCamp Introduction to Git eğitimini tamamlayın.
4. PREP-03: DataCamp Introduction to GitHub Concepts eğitimini tamamlayın.

Son tarihler, notlandırma ve resmî duyurular DYS'de paylaşılır. Hazırlık
depoları, materyaller ve teslim kayıtları GitHub'da yer alır. Her iki sistemi de
düzenli olarak takip etmek öğrencinin sorumluluğundadır.

Herhangi bir sorun veya belirsizlik varsa, son tarihten önce DYS'de duyurulan
iletişim adresi üzerinden soru sorun. Son tarih geçtikten sonra ilk kez iletilen
teknik sorunlar veya takip edilmemiş duyurular, tek başına ek süre gerekçesi
oluşturmaz.
