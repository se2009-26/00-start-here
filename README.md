# Start Here: GitHub and Lab Preparation

## English

This repository is the starting point for the course GitHub workflow. Read the two
documents below before beginning any preparation work.

- [Lab Rules and Academic Integrity Notice](resources/Lab-Rules.pdf)
- [GitHub Account Setup Guide](resources/GitHub-Account-Setup-Guide.pdf)

### Preparation sequence

Complete the assigned preparation repositories in this order. The exact deadlines
are announced in DYS.

| Order | Repository | Task |
| --- | --- | --- |
| 1 | prep-00-lab-rules | Read the rules and submit the acknowledgement |
| 2 | prep-01-github-account-and-workflow | Practice commit, branch, pull request, and merge |
| 3 | prep-02-datacamp-introduction-to-git | Complete Introduction to Git |
| 4 | prep-03-datacamp-introduction-to-github-concepts | Complete Introduction to GitHub Concepts |

### Official channels

- DYS: announcements, deadlines, grades, and the contact address for questions.
- GitHub: preparation repositories, materials, commits, pull requests, and
  submissions.

Check both DYS and GitHub regularly. Ask questions through the contact address
announced in DYS before the deadline; do not wait until a deadline has passed.

### External training

- [DataCamp: Introduction to Git](https://app.datacamp.com/learn/courses/introduction-to-git)
- [DataCamp: Introduction to GitHub Concepts](https://app.datacamp.com/learn/courses/introduction-to-github-concepts)

Use only your own work and your own GitHub account. Do not share passwords,
recovery codes, or two-factor authentication codes with anyone.

## Türkçe

Bu depo, dersin GitHub işleyişi için başlangıç noktasıdır. Herhangi bir hazırlık
çalışmasına başlamadan önce aşağıdaki iki belgeyi okuyun.

- [Laboratuvar Kuralları ve Akademik Dürüstlük Bildirimi](resources/Lab-Rules.pdf)
- [GitHub Hesap Açma Kılavuzu](resources/GitHub-Account-Setup-Guide.pdf)

### Hazırlık sırası

Atanan hazırlık depolarını aşağıdaki sırayla tamamlayın. Kesin son tarihler DYS
üzerinden duyurulur.

| Sıra | Depo | Görev |
| --- | --- | --- |
| 1 | prep-00-lab-rules | Kuralları okuyun ve onayınızı gönderin |
| 2 | prep-01-github-account-and-workflow | Commit, branch, pull request ve merge akışını uygulayın |
| 3 | prep-02-datacamp-introduction-to-git | Introduction to Git eğitimini tamamlayın |
| 4 | prep-03-datacamp-introduction-to-github-concepts | Introduction to GitHub Concepts eğitimini tamamlayın |

### Resmî kanallar

- DYS: duyurular, son tarihler, notlar ve soru iletişim adresi.
- GitHub: hazırlık depoları, materyaller, commitler, pull requestler ve
  teslimler.

DYS ve GitHub'ı düzenli kontrol edin. Sorularınızı son tarihten önce DYS'de
duyurulan iletişim adresi üzerinden iletin.

Haricî eğitim bağlantıları:

- [DataCamp: Introduction to Git](https://app.datacamp.com/learn/courses/introduction-to-git)
- [DataCamp: Introduction to GitHub Concepts](https://app.datacamp.com/learn/courses/introduction-to-github-concepts)

Yalnızca kendi çalışmanızı ve kendi GitHub hesabınızı kullanın. Parolanızı,
kurtarma kodlarınızı veya iki aşamalı doğrulama kodlarınızı kimseyle paylaşmayın.
